# 扩展管理器（Extension Manager）

一个纯前端的 SillyTavern UI 扩展，用来增强左侧「扩展」设置抽屉：吸顶顶栏、搜索扩展、已展开扩展标签页、一键折叠、自定义分组，以及可选的顶栏主题。

针对 **SillyTavern 1.16.0** 编写，不需要服务端插件，不修改 SillyTavern 本体文件。

## 功能

- **吸顶顶栏**：标题、通知开关、搜索、标签页固定在抽屉顶部，滚动时不会被推出，无阴影。
- **搜索扩展**：按扩展标题实时过滤，支持中文标题和 `data-i18n` 英文键名；显示匹配数量，Esc 清空。
- **已展开标签页**：展开的扩展出现在标签条里，点击跳转；标签过多可横向滚动，当前标签只用描边高亮，不改变背景色。标签名超过字数上限时自动省略，悬停显示全名。
- **一键折叠**：标签条右侧的向内收拢图标折叠全部；每个标签的 ✕ 单独折叠。
- **收纳顶栏按钮**：默认把「管理扩展 / 安装扩展」收进 ⋯ 菜单，仍调用 ST 原生弹窗；切回原生按钮时，⋯ 按钮会一起隐藏。
- **分组标题行**：开启分组展示后，「分组列表」标题行停靠在标签条正下方并随顶栏吸顶；右侧两个图标一键展开 / 折叠全部分组。标签条出现横向滚动条时该行高度不变，不会挤压下面的列表。
- **管理分组**：齿轮菜单里点「管理分组」打开居中弹窗。每个分组一行，只显示拖动柄、展开箭头、分组名、启用开关、编辑图标和删除图标；点箭头查看组内插件，拖动行首手柄可调整分组顺序，点删除会先弹出二次确认，删除后可用提示条上的「撤销」恢复。弹窗固定高度，分组多时在弹窗内滚动。新建分组后会自动进入「编辑分组」弹窗，分组名重复时会就地报错。页脚右侧可将分组配置「导出」为 JSON 文件，或从 JSON 文件「导入」替换现有分组。
- **编辑分组**：改名和调整成员都在这里完成。分组名下方是本组插件的竖排列表，每行带拖动柄与序号，按住行上下拖动即可排序，顺序即抽屉里的显示顺序（也可聚焦某行后按 Alt+↑ / Alt+↓ 换位）；下方「未分组 / 其他分组」列表中点 + 绑定到本组：未分组直接加入，其他分组里的插件会先确认是否从原分组移走；点行尾的 × 移出同样先确认。保存分组后弹出居中提示条。一个扩展只能属于一个分组。开启分组展示后，扩展按分组分栏显示，组内顺序与编辑弹窗中的列表顺序一致，可单独折叠分组，搜索时自动展开。
- **分组归属按稳定标识记录**：以扩展抽屉的 id、data-i18n 键或标题三者之一作为成员标识，改显示名或切换界面语言不会让扩展从分组里掉出去；旧版本按标题保存的分组会在加载时自动迁移。
- **图标提示**：分组列表标题、两个弹窗标题，以及导入 / 导出 / 保存 / 取消按钮都带图标；弹窗右上角关闭叉号比其他图标按钮更大，便于点中。展开 / 收起统一用右向与下向两个独立箭头切换，不旋转单个图标，状态与位置始终稳定。
- **键盘与无障碍**：管理 / 编辑弹窗打开后 Tab 焦点被限制在弹窗内，关闭后焦点回到打开它的按钮；编辑弹窗的两个页签支持左右方向键切换。
- **隐藏内置区块**：一个开关同时隐藏「下载扩展和资源菜单」和「(已弃用) 扩展API」区块。
- **顶栏主题**：跟随酒馆 / 日间 / 夜间，只作用于本扩展的吸顶顶栏及其中的标签、搜索框与菜单，不改 ST 全局主题，也不改下方的分组列表与弹窗。
- **扩展设置**：列表里的「扩展管理器」可开关搜索框、按钮收纳、隐藏内置区块，设置标签字数上限。

## 通过 GitHub 安装（推荐）

1. 打开 SillyTavern 左侧「扩展」抽屉。
2. 点击「安装扩展」（Install extension）。
3. 粘贴仓库地址：

   ```
   https://github.com/Fenaunn1/ST-Extension-Manager
   ```

4. 确认后刷新页面（建议 Ctrl+F5）。

之后可在扩展列表的「扩展管理器」里调整设置。

## 手动安装

把整个 `ST-Extension-Manager` 文件夹放到下面任一位置，然后刷新页面：

- 用户级：`<SillyTavern>/data/<用户名或 default-user>/extensions/ST-Extension-Manager/`
- 全局：`<SillyTavern>/public/scripts/extensions/third-party/ST-Extension-Manager/`

## 使用

1. 打开「扩展」抽屉，顶部会出现搜索框和标签条。
2. 展开任意扩展后，它会出现在标签条中；点击标签跳转，✕ 折叠单个，右侧一键全部折叠。
3. 点顶栏右侧 ⋯ 打开菜单：
   - **设置界面**：跳到本扩展的设置抽屉。
   - **管理分组**：打开分组列表；点箭头查看组内插件，点编辑图标改名或调整成员，点开关启用/停用，点删除图标二次确认后删除。
   - **启用分组**：开关分组视图。
4. 编辑分组时，分组名下方是本组插件的竖排列表，按住行上下拖动（或聚焦后 Alt+↑ / ↓）调整顺序。在「未分组」里点 + 直接加入本组；在「其他分组」里点 + 会先确认一次「从哪个分组移动到本组」，因为这会改变另一个分组的内容。点行尾 × 移出同样先确认。移动插件不会重复出现。
5. 点取消 / × / 背板退出编辑时，若有未保存的改动会先问一句；保存成功用底部浮出的提示条告知，不打断操作。
6. 在手机上，管理分组和编辑分组会铺满整屏，底部按钮贴合安全区；确认框和提示条始终居中或贴底，不会移出可视区。

## 设置项

设置保存在 `extension_settings.extension_manager`（会从旧的 `extension_manager_plus` 自动迁移）：

| 键 | 默认 | 说明 |
| --- | --- | --- |
| `theme` | `auto` | 顶栏主题：`auto` 跟随酒馆，`day` 日间，`night` 夜间。固定调色板只覆盖吸顶顶栏 |
| `showSearch` | `true` | 显示搜索框 |
| `compactActions` | `true` | 收纳顶部按钮，把管理与安装收进 ⋯ 菜单；关闭时隐藏 ⋯ |
| `hideBuiltins` | `false` | 隐藏「下载扩展和资源菜单」和「(已弃用) 扩展API」区块 |
| `tabLabelClip` | `true` | 是否按字数上限截断标签；关闭后标签显示完整名称 |
| `tabLabelMax` | `5` | 标签显示的最大字符数（2–10），超出用 … 省略 |
| `grouping` | `false` | 是否启用分组展示 |
| `groups` | `[]` | 分组列表：`{ id, name, enabled, collapsed, members }`，`members` 存稳定标识（`id:` / `i18n:` / `title:` 前缀 + 值） |
| `ungroupedCollapsed` | `false` | 「未分组」区块是否折叠，与普通分组一样持久化 |

## 兼容性与限制

- 依赖 SillyTavern 的 `#rm_extensions_block`、`.extensions_block`、`.inline-drawer` 结构；ST 大改版后可能需要同步选择器。
- 只处理「扩展」抽屉里的顶层设置抽屉，不会把扩展内部的嵌套折叠项当成独立扩展。
- 分组视图会把扩展抽屉移动到分组容器里；关闭分组会按原位置放回。
- 仅操作页面 DOM/CSS，不发起额外网络请求；设置通过 SillyTavern 自带的设置保存机制持久化。
- 使用 `color-mix()` 等现代 CSS；Chrome / Edge 105+、Firefox 121+ 正常。

## 文件结构

```text
ST-Extension-Manager/
├─ manifest.json      # display_name = 扩展管理器，loading_order = 1000
├─ index.js           # 入口，只负责 import { boot } 并调用
├─ core.js            # 设置、常量、状态、标题与分区工具
├─ dom.js             # DOM 查询、抽屉枚举、可见性
├─ builtins.js        # 内置区块识别
├─ groups.js          # 分组渲染、折叠、分组行与管理弹窗条目
├─ group-editor.js    # 编辑分组弹窗、成员绑定与拖拽排序
├─ modal.js           # 弹窗层、焦点陷阱、确认框、提示条
├─ toolbar.js         # 吸顶顶栏、搜索、标签条、菜单
├─ theme.js           # 顶栏主题与滚动同步
├─ render.js          # 过滤、排序与重绘调度
├─ events.js          # 事件绑定、观察器与启动
├─ style.css          # 主样式表：只用 @import 按顺序引入 css/ 下的模块
├─ css/
│  ├─ tokens.css      # 设计令牌、吸顶栏外壳、日间 / 夜间调色板
│  ├─ toolbar.css     # 搜索行、标签行、图标按钮、⋯ 菜单
│  ├─ panels.css      # 搜索结果、设置抽屉、分组列表、齿轮菜单、内置区块
│  ├─ modal.css       # 浮层外壳与动效、分组管理行、开关
│  ├─ group-edit.css  # 编辑分组弹窗、页脚按钮、二次确认框
│  ├─ toast.css       # 提示条
│  └─ responsive.css  # 窄屏整屏弹窗
└─ README.md
```

所有 JS 模块都是同目录 ES module，由 SillyTavern 直接以 `<script type="module">` 加载，不需要构建步骤。

SillyTavern 每个扩展只加载 `manifest.json` 里 `css` 指定的那一个样式表，所以样式拆成多个文件后由 `style.css` 顶部的 `@import` 引入。`@import` 必须写在所有规则之前，**文件顺序就是层叠顺序**：追加新的模块文件要加在列表末尾，否则可能改变已有规则的优先级。
